##  Featured Projects

### 🔹 [SignSpeak — Speech to Sign Language Conversion](https://speech-to-sign-language.vercel.app/home)
>  Best Research Paper · ICICRCET 2025 &nbsp;|&nbsp; 📄 Published · IJCRT Vol. 13 Issue 9 (UGC Certified)

End-to-end AI system converting spoken English to Indian Sign Language in real time. Combines Wav2Vec 2.0 ASR, NLP pipelines optimized for sign grammar, MediaPipe Holistic 33-point skeletal tracking, and Blender 3D animations for naturalistic hand gestures, facial cues, and body posture.

`Wav2Vec 2.0` `MediaPipe` `NLP` `Blender` `React` `Python` `JavaScript`

---

### 🔹 [Deepfake Audio Detection using Autoencoders & Wav2Vec](https://thegrenze.com/index.php?display=page&view=journalabstract&absid=6138&id=8)
>  Published · H1nweiss Aret · Scopus Indexed · Apr 2026

Deep learning pipeline to identify AI-generated speech using Wav2Vec embeddings, noise reduction, spectrogram generation, and autoencoder-based anomaly detection. Reconstruction error distributions are used to reliably distinguish authentic from synthesized audio.

`Wav2Vec` `Autoencoders` `PyTorch` `Librosa` `Flask` `Python`

---

### 🔹 Agentic Financial News Researcher
Multi-agent Python system using the Claude SDK that autonomously retrieves, filters, and synthesizes financial news into structured reports — no human in the loop once the query is submitted. Features tool-use orchestration, error recovery, and modular agent roles.

`Claude SDK` `Multi-Agent` `RAG` `Python` `LLM Pipelines`

---

### 🔹 Hallucination Analysis in Vision-Language Models
Research pipeline testing whether ViT encoder attention entropy predicts hallucination in LLaVA-1.5-7B on 1,000+ COCO val images. Validated with Spearman correlation, Mann-Whitney U, and Kruskal-Wallis statistical tests. T4 GPU memory optimized.

`LLaVA-1.5` `ViT` `PyTorch` `SciPy` `Transformers` `COCO API`

---

### 🔹 Women Safety Analytics
Multi-model real-time pipeline combining person detection, gender classification (OpenCV), gesture recognition (MediaPipe), autoencoder anomaly detection, and Folium geospatial heatmaps to identify high-risk regions and situations.

`OpenCV` `MediaPipe` `PyTorch` `Folium` `Scikit-learn` `Python`

---

### 🔹 Scan It Know It — AI Product Label Scanner
Mobile-first app using Gemini 2.5 Flash to scan product labels and instantly analyze ingredients with a semantic color scoring system (green/amber/red). Full 6-screen UX with React/TypeScript frontend and Express backend.

`Gemini 2.5 Flash` `React` `TypeScript` `Express` `Tailwind CSS`
